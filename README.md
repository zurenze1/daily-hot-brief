# 每日热点早报 · 开源阅读工具

[打开工具](https://zurenze1.github.io/daily-hot-brief/)

只分享功能，不分享作者已采集的资料。默认页面为空，没有真实新闻、历史日报、个人IP资料、数据库或账号信息。

## 可以做什么

- 导入使用者自己的JSON早报，支持多期、多文件。
- 按人物、财经、时尚界、服装、AI及其他栏目查看。
- 按日期、标题、人物、来源和关键词筛选。
- 展开摘要、整理者思考与原文链接。
- 清空页面；同日期重新导入会替换当前页面内的该期版本。

文件只在浏览器当前页面内存中读取，不上传服务器、不写入浏览器持久存储，刷新后清空。页面可选择“体验虚构示例”或下载虚构格式示例；全部示例人物和事件均为虚构。

本项目是独立的只读阅读工具，不包含联网采集、AI生成、自动日更或作者本机IP工作台的后台。使用者自行提供资料或接入自己的数据源；不需要作者账号或API密钥。

## 导入格式

```json
{
  "day": "2026-01-02",
  "news": [{
    "channel": "people",
    "title": "虚构示例：人物甲的一次选择",
    "facts": "仅用于说明格式，不对应真实新闻。",
    "analysis": "整理者自己的思考，可留空。",
    "sources": [{"name":"示例域名","url":"https://example.com/"}]
  }]
}
```

channel支持people、culture、apparel、ai、finance、other。可选category、person、publishedAt；facts也可以是字符串数组。导入多个日期时，可以用上述对象的数组，或分别选择多个JSON文件。未知字段忽略，不显示模型配置、账号或其他非新闻字段。

单文件最多5MB，一次文件总量20MB；单期5000条、页面总计10000条。导入出错时保留原页面资料。非法日期会拒绝；不安全或带凭据的链接不会成为来源按钮。工具不核实新闻事实，也不替代来源审阅。

## 本机运行与开发

需要Node.js 20或更新版本，无第三方运行依赖：

```sh
npm start
```

打开 http://127.0.0.1:4890/ 。PORT环境变量可以修改端口。直接双击HTML可能受到浏览器模块限制，建议使用上面的静态服务或在线地址。

```sh
npm test
```

web/是完整静态页面，可部署到GitHub Pages或其他静态托管。只发布web，不放使用者的资料文件。浏览器没有外部数据请求；来源链接仅在使用者主动点击时打开。
